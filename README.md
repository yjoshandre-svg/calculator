# Calculator

A basic calculator built with HTML, CSS, and JavaScript for The Odin Project.

## Features

- Add, subtract, multiply, and divide
- Chained operations (12 + 7 - 1 = 18)
- Decimal input, with only one decimal point allowed
- Backspace and clear (AC)
- Keyboard support
- Snarky divide-by-zero message
